# MyMental – Mood & Productivity Tracker

A Django-based web application that allows users to track their daily mood and productivity, manage tasks through a to-do list, and review personal statistics.

### Features

* User registration and authentication
* Daily mood and productivity ratings
* Personal statistics tracking
* To-do list

### Technologies

Python · Django · HTML · CSS

### Deployment

Deployed on Render. The application may take a few seconds to start.
